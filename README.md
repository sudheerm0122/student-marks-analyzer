# Student Marks Analysis using Python 📊

This project reads student marks from a CSV file and performs basic data analysis using Python.

## 📌 Features
- Read data from CSV file
- Calculate average marks
- Find highest and lowest marks
- Display pass/fail status for each student
- Uses Python file handling and CSV module

## 📂 Files Included
- `marks.csv` – Student marks data
- `marks_analysis.py` – Python program for analysis
- `README.md` – Project documentation
